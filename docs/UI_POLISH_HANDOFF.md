## 自動驗收

- `cd frontend` 後執行 `npm.cmd run check`（編譯及 Vitest）。
- 新增測試涵蓋提示計時、手動關閉、暫停／恢復、卸載清理、年度變化及來源勾選。
- 瀏覽器流程：`output/playwright/refinements-check.js`；後端失敗使用攔截的 503 回應，沒有觸發真實抓取或 AI 費用。
- 1280×720：導覽列與卡片皆 920px 寬；導覽列 44px 高，指標卡片約從 y=158 至 y=668，首屏可完整看見。
- 1920×1080：卡片約從 y=158 至 y=755。
- 390×844：無水平溢出，卡片從 y=231 開始；手機與長內容頁仍需垂直捲動，未縮字或裁切內容以強塞首屏。
- H 抽屜、Escape 關閉、來源勾選與提示自動消失經實際瀏覽器操作；未出現新的 JavaScript 執行錯誤。測試模擬的 503 網路錯誤屬預期。
