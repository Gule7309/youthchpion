瀏覽器原生 200% 縮放：自動化快捷鍵未改變實際縮放，不能用等效視窗冒稱已實測；OpenSpec 5.2 因此保留未勾選。建議再以實體手機確認標題滑動手感與一般動畫的主觀順暢度。

## 驗收路徑

1. 開啟前端，從指標直接點報告，再由側夾選診斷；首尾沒有循環。
2. 論證往下閱讀後切走再回來；滾輪只閱讀當頁。
3. 在論證切換職業，再看風險／報告，對象須一致。
4. 開資料來源，試 Esc、遮罩及關閉；來源按鈕恢復焦點。
5. 縮小到手機寬度，以及瀏覽器選單設定 200%，確認五頁都能讀完。
