# 指標說明側滑卡

- 指標分頁 S／A／B／C／H／D 整張卡可點擊，開啟右側單一 dialog，不改網址、不產生分析請求。
- 使用 button 語意、連結樣式提示與 aria-haspopup；不是另開網站。鍵盤、關閉按鈕、Escape 與遮罩沿用現有詳情機制，關閉回到原卡片焦點。
- 內容：意涵、計算方式、解讀、目前限制。S 與 H 延用 v0.4 候選式；B 聚合未核定，僅列流程；A／C／D 列定義或候選加權方式，不計算新的正式分數。
- 動態：右側滑入 240ms，鍵盤操作、系統減少動態或網站關閉動畫時不播放。手機全寬，長公式換行。
- 不修改後端、模型計算、數值、資料來源或先前待修的導覽定位。
- 核心內容位於 frontend/src/indicatorHelp.tsx；未來應隨後端核定的模型版本更新說明。
