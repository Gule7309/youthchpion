## 後端待辦／不可直接沿用的欄位

1. 新版 18–35 歲 A 與旧版 `youth_employment_share` 不同，須核對年齡估算與職業內分母，不能改標籤代替實作。
2. B 核對 ILO 到台灣分類的 crosswalk、權重、來源年與覆蓋率。
3. C 核對分產業 Ready/Scaling 原始值與職業產業權重；Ready 含準備／試驗，不等於實際導入。
4. H 提供兩期原始值、期間、候選／核定公式版本；缺值及零基期回傳 unavailable，而非零。
5. D 提供完整擷取覆蓋、去重及 AI 判定方式；占比、排名母體／同名次規則、可比歷史各自有可用狀態。不得直接使用旧 `ai_entry_opportunity_rate` 冒充。
6. 政策 evidence ID 須可解析至核對原文與定位；職業、快照版本、適用限制、KPI 未提供時不編造。
7. 新版 API 契約尚未凍結。每項應有 value/null、status、reason、unit、population、period、source、methodVersion；區分 snapshotId、retrievedAt、publishedAt、checkedAt，不能混寫日期。
