# 政策決策流程：前端交接與驗收紀錄

更新：2026-09-12。對應 OpenSpec：`complete-policy-decision-workflow`。

## 已實作的範圍

- 保留五頁檔案夾，新增摘要至風險、風險至判讀、判讀至證據、證據至政策的內容入口。
- 顯示觀測／推論／假說及逐項支持／反證／限制／背景關聯；來源存在不等於支持政策。
- 證據詳情顯示來源、適用範圍、核對日期、原文定位及限制；關閉後回到觸發按鈕。
- 政策比較與選取元件支援零、一、多個選項。初始不代選，缺必要引用不能納入；未知成本／KPI 顯示待確認。
- 政策選擇依職業與分析版本隔離，只在記憶體保存。同版本返回可恢復，新版本不遷移。
- 本機整理固定快照草稿：有有效選取政策則為政策討論草稿，否則為監測摘要；全部不可用時不能產生空白報告。
- 報告含完整指標表、招募圖、判讀、相關引用、限制及版本；提供瀏覽器列印／另存 PDF 入口，不宣稱 AI 已生成或檔案已儲存。

## 正式 Demo 目前可做什麼

以現有勞動部核對快照，完成「整體求才觀測 → 原始依據 → 監測摘要」。沿用三個職業及 2024、2025 原始值，沒有更改候選 Risk 公式或填入缺值。

資料是全國、全年齡新登記求才人次，不是 18–35 歲青年新人職缺。18–35 是分析目標，不能當作這份資料的實際年齡範圍。職業分類版本、精確抓取時間及 SHA-256 沒有記錄，仍明示未知。

正式資料沒有核對完成的政策選項，所以正式畫面不會顯示虛構方案。政策比較、納入與長報告的互動驗證使用隔離 fixture；測試成功不代表真實政策已可交付。

## 後端／資料需共同確認

以下均為待交接，不是現有 API 已支援的宣告。語意欄位詳見 OpenSpec 的 `design.md`。

1. 穩定且一致發布的 analysisId、modelVersion、職業代碼／分類版本、來源期間、核對／發布時間與可用狀態。
2. 逐項 claimId、判讀種類、指標引用，及包含角色、理由、適用性核對狀態的研究關聯。
3. 研究 evidenceId、作者、日期、來源類型、摘要／直接引文分離、原文 URL 與定位、族群／地區／方法限制。
4. 政策 optionId、職業、措施／機制、執行條件／合作方／成本或負擔、效益、KPI、限制與必要引用。
5. 誰負責研究與政策適用性的核對；第一個完整真實職業案例由誰簽核。
6. 正式端點、驗證方式、更新排程及錯誤契約。新 API 未定稿前，不以 TypeScript 型別代替外部 JSON 的執行期驗證。

現有刷新仍呼叫舊管線，拒絕將舊 20–29 歲回應覆蓋目前快照。**新版快照的執行期驗證、原子發布及遲到 API 回應防護尚未完成串接**；已完成的是前端內容導覽、選擇與報告的上下文隔離，不是新版後端管線。

## 2026-09-13 最終確認：限寬、自動高度、整頁捲動

本節取代前節的「600px 高度上限／卡片內捲動」設定。

- 卡片仍置中限寬 920px、導覽列限寬 1040px；高度由目前內容決定，沒有固定高度上限。
- 所有視窗統一使用網頁捲動，卡片不設內部捲軸；滾輪不切換五個分頁。
- 導覽選取色恢復原本黑色，捲動時導覽列保持可見。內容跳轉保留頂部間距，避免被導覽遮擋。
- 整頁閱讀位置按分頁、職業及快照記憶；開啟詳情時鎖住背景捲動。內容高度變更不應取消正在進行的檔案夾動畫。
- 實際滾輪測試：論證頁 window.scrollY 由 0 增至約 319px、卡片 scrollTop 維持 0、hash 保持 #evidence；離開再返回可恢復原位置。
- 兩個舊內捲行為測試已依本次確認改為整頁捲動契約；不是把舊契約的失敗當作通過。
