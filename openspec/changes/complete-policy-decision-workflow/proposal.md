## Why

目前五頁檔案夾介面已具備閱讀與切換基礎，但職業診斷、研究證據與政策報告之間仍缺少可追溯的操作路徑。這次補齊從「理解青年就業風險」到「帶著證據討論政策」的流程，讓 Demo 能展示決策輔助價值，而不只是展示指標。

## What Changes

- 保留指標、風險、診斷、論證、報告五頁、非循環切換、滾輪只閱讀當頁與既有動畫設定。
- 指標頁增加精簡分析摘要；風險與診斷提供前往特定判讀及其證據的入口。
- 建立判讀與證據的逐項關聯，呈現支持、反證、限制、背景，以及原文定位與適用範圍。
- 報告頁以一致欄位比較可用政策選項，允許使用者選擇納入會議草稿；沒有足夠證據時不湊數。
- 從目前已核對內容整理固定版本的報告預覽，支援瀏覽器列印／另存 PDF；不假稱完成 AI 生成或檔案下載。
- 補上跨職業、跨版本、資料不足、鍵盤操作、短視窗與列印的驗收條件。
- 明訂前端顯示模型與後端交接責任；正式展示仍須使用真實數據與已核對來源。

## Capabilities

### New Capabilities

- `policy-decision-workflow`: 職業判讀、證據查核、政策比較與選取、會議草稿預覽及列印的可追溯流程。

### Modified Capabilities

無。建立時 `openspec/specs/` 尚無已發布能力。此變更延伸進行中的 `define-youth-policy-dashboard` 與 `add-folder-swiper-navigation`，不重寫兩者既有規格。原先報告不匯出的範圍，本次僅延伸至本機預覽與瀏覽器列印，不包含後端 PDF 或 PPTX 產製。

## Impact

- 預期實作接點：`frontend/src/App.tsx` 的職業／快照狀態、`FolderWorkspace.tsx` 的內容導覽、`FolderPages.tsx` 的五頁內容，以及相應樣式、資料轉接與測試。
- 後端需提供穩定分析版本、判讀 ID、證據關聯、政策選項與可用狀態；此規格提出語意欄位，不宣稱 API 已存在。
- 不修改 A/B/C/H/D、S、Risk 公式，不改以職業為主要比較單位及 18–35 歲目標族群。
- 不新增登入、資料庫、聊天室、畫布、AI 自動生成、即時爬取服務或 AWS 部署；不以示意數據補正式資料缺口。
- 本次交付僅為 OpenSpec 文件；程式實作、測試執行、commit 與 push 不屬於此次操作。
