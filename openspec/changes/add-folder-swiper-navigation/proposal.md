## Why

目前 UI 將指標、比較、診斷、研究與政策全部放在長頁面，切換方式仍是錨點捲動。使用者希望依參考圖改為五個檔案夾式分頁：一次聚焦一份內容，又能從頂部導覽與側邊收合檔案夾理解所在位置，並有連續、滑順的切換感。

## What Changes

- **BREAKING（資訊架構）**：以「指標 → 風險 → 診斷 → 論證 → 報告」五頁取代目前左側直式導覽與三欄長頁；仍為同一個前端工作區，不是五個網站，也不是必須逐步完成的流程。
- 中央只展開目前分頁，兩側用收合檔案夾表達前後頁；頂部導覽可直達任一頁並同步顯示目前選取。
- 採使用者已確認的**非循環**順序：指標之前沒有上一頁，報告之後沒有下一頁；不複製頁面製造無限輪播。
- 採使用者已確認的**滾輪只閱讀當頁**：不將垂直或水平 wheel 事件轉成換頁，不在內容底部自動換頁。觸控換頁限定檔案夾標題的手勢區。
- 定義檔案夾展開／收合、位移與導覽選取的協同動畫；支援快速改選、系統減少動態效果、鍵盤與窄螢幕。
- 五頁共用選取職業與資料版本；切頁保留閱讀位置、已展開的內容及既有資料，不重新抓取或計算模型。
- 保留真實快照、未核定風險不評分、研究限制、來源詳情與尚不可用的報告入口，不為新外觀補造內容。

## Capabilities

### New Capabilities

- `folder-swiper-navigation`：五頁內容分工、非循環檔案夾導覽、平順切換、閱讀狀態、響應式與可及性，以及既有資料行為的保留。

### Modified Capabilities

無已發布 capability。`openspec list --specs --json` 目前為空；`define-youth-policy-dashboard` 是尚未歸檔的另一份提案，不能當作正式規格直接寫 MODIFIED delta。

本提案核准後，五頁布局將取代該舊提案中「三區同時直接呈現」及「頁首三區錨點」的布局決策；其職業、模型、來源與資料誠實性約束仍保留。實作交接時須同步舊提案中的布局段落，不能將兩種互斥布局同時當作驗收條件；本次不覆寫或歸檔舊提案。

## Impact

- 本輪僅新增本 change 的 `proposal.md`、`specs/folder-swiper-navigation/spec.md`、`design.md`、`tasks.md`，不修改應用程式、不 commit／push。
- 後續實作範圍為 `frontend/src/App.tsx`、`policyDashboard.css`、分頁／導覽元件與 `ReviewDashboard.test.tsx`；沿用 `Icon.tsx`、資料讀取與詳情功能，保留 `LegacyApp.tsx`。
- 不要求新增 Swiper、動畫或平滑捲動套件；「swiper」指互動形態，是否需要套件由後續實作驗證決定。
- 不改 `verifiedSnapshot.ts` 中的真實資料與 `annualChange` 算法，不改 `api.ts`、後端、資料清洗、模型定義或部署。未來正式資料與報告服務的交接邊界列於 `design.md`。

## Non-goals

本提案不新增登入、筆記本、自由白板、聊天、檔案上傳、自動播放、無限輪播、滾輪劫持、全頁 3D 翻轉、報告編輯器或檔案匯出。完成 UI 不代表新版模型、正式資料管線與政策報告服務已完成。
